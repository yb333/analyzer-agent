# 17 · 需求 SPEC 列级映射矩阵（xlsx 各列 ← 原料 + 处理方式）

> 读者：analyzer 侧维护会话 + SPEC 通道实现/评审。本表是 **SPEC 通道（人向 xlsx 交付）的
> 实施合同**：对齐靶 = `docs/需求SPEC.xlsx`（模板列头逐字基准，含全角/半角陷阱），
> 形态参照 = `docs/需求SPEC-案例mock-DWB_CUST_ASSET_D.xlsx`（黄金案例手工设计稿）。
> 每列标注处理方式与来源制品，实现与评审按本表逐列对账。
>
> **定位**：SPEC = ViewContext（v1.7 三视图公共取数层）+ LTS 调度匹配的 **xlsx 渲染**，
> 独立人向交付通道——不是 facts 服务的 format（消费方/契约节奏/校验体系不同，
> 见 §九）。与 asset_facts / ts_draft **同源同口径**：共享制品装配、解析引擎、
> ViewContext，一条解析链保证一致性。

## 处理方式标注

| 标 | 含义 | 纪律 |
|---|---|---|
| **R** 恢复 | 制品/引擎事实确定性还原（原文或既有事实） | 逐字保真优先（SQL/别名/条件照抄代码样子） |
| **D** 派生 | 确定性计算/渲染（copy、拼接、匹配、拆解） | 文法/结构推导，非语义判断 |
| **E** 留空 | 静态分析不可得或人工位 → 合法留空 | 不编造（`//` 前缀纪律沿 154c435） |
| **N** 不产 | 决策明确不填 | 记录ID 等 |

来源缩写：**术加** = 术加制品 excel；**LTS** = LTS 制品 excel；**DDL** = DDL 文件；
**VC** = ViewContext/引擎派生。

## 〇、通道与命令形态

```
python dws-pipeline-analyzer/run.py spec --dir {制品目录} --output {xlsx路径} [--scenario {场景名}]
```

- 输入装配**复用** `assemble_artifact_dir`（指纹分拣，docs/15）：术加必选、LTS 可选、
  DDL 可选；**DQ 在 SPEC 通道忽略且不告警**（用户决策 Q8）。
- 退出码对齐 facts 纪律：0 交卷 / 1 制品问题 / 2 参数错误；stdout locator
  `spec: {path}` + `self_check: {verdict}`，附人话披露（面向人，非 agent 协议）。
- **面向人的封装 = `commands/export-spec.md`（/export-spec）**：场景门失败时
  stderr 附机器行 `scenarios: …` 供封装弹选择；`--output` 可省略（默认
  `./output/需求SPEC-{规则组英文名}.xlsx`）；人工位/两态/self_check 三态的
  解读引导都在命令文档里。
- **多场景资产**（引擎识别 exec_sequence+分区分组 >1 场景）：`--scenario` 指定后按该
  场景产出单场景视图；未指定 → 不产文件，交付门提示「多场景资产，请指定场景」
  （用户决策：v1 单场景设计，方案 A）。

## 三、Sheet 3 表关联（行集语义一列全包）

| 列 | 标 | 来源 | 规则 |
|---|---|---|---|
| 记录ID | D | — | 顺序生成 1..n（实测修订） |
| *左表 / 左表别名 | R | 术加→VC | 物理表名 + SQL 内真实别名；左表=主表（驱动表） |
| *右表 / 右表别名 | R | 术加→VC | **右表=物理表名**（CTE/子查询不是表）；右别名=该表在预处理代码**内部**的别名，无则空（D2） |
| *关联方式 | D | VC | **归一标准枚举**（实测修订）：LEFT/RIGHT/INNER/FULL/CROSS JOIN（裸 JOIN→INNER，去 OUTER，2026-11-02） |
| *关联条件&限制条件 | R | VC | **行集语义全包**，分段见下 |

**G 列段式语法**（`;` 分段，按需出现）：

```
{ON 原文——预处理后别名照抄，即真实代码的样子}
；限制：{表级 WHERE，表内别名}
；写入前限制：{中间表/终态写入前的行级过滤（单场景口径）}
；预处理：{与该右表相关的 CTE/开窗/分组链 SQL 原文贴码}
；主表链预处理：{发生在主表链下游的分组汇总/去重/保留条件（HAVING 语义）}
```

- **谓词归属铁律**（行集 vs 成值二分，用户决策统一规则）：

| 谓词类 | 归宿 |
|---|---|
| 表级 WHERE（源表/join 上） | Sheet3「限制」 |
| 写入前行级过滤（含分区条件） | Sheet3「写入前限制」 |
| 取位/去重（`rn=1` 类） | Sheet3「限制」，开窗进「预处理」贴码 |
| 防重 NOT EXISTS（目标表自身） | Sheet3「限制」（单表行，见下） |
| 分组粒度 + 分组保留（HAVING） | Sheet3「主表链预处理」 |
| 表达式/聚合/CASE/常量 | Sheet4 加工逻辑（成值语义） |

- **单表无关联资产**：仍占一行，右表填「—（无关联）」，行级限制（含防重）落 G 列
  （E1 决策，微调并取代 C1 的「Sheet4 备注」方案）。
- **多物理源 CTE 场景**（case_17 形态）：主表=驱动表，其余物理源各一行；
  预处理贴码只贴**与该右表相关的 CTE 定义链**（含其依赖的上游 CTE），不贴全量 WITH。
- **嵌套子查询场景**（case_27 形态，`a JOIN ((e⋈g WHERE …) GROUP BY …) b JOIN f`，
  2026-11-02 方案）：**与 CTE 完全同构**——main-subquery 行：右表=子查询主物理源
  （join_paths.subquery_tables 的 main 项），右别名=外层别名（ON 里真实引用的样子），
  ON 原文 + 预处理贴子查询原文（从 raw_sql 括号配平提取，逐字）；子查询内部的
  关联/过滤/分组**不单独成行**（信息全收贴码）；引擎展开的 JOIN_SUBQUERY_* 空条件
  行移除（会造成「a 直接关联 e/g」的误导）；外层 join 关键字从 raw_sql 回看前置词
  归一（引擎 join_type 只记 JOIN_SUBQUERY 无方向）。

| *备注 | D | — | 穿透链说明（`tmp_x(R1)→tmp_y(R2)→终态`）、常量字段口径、表3 引用等 |

- **资产字段列零重复（实测修订③）**：多来源字段（如 CASE WHEN 引用 a/b）合并为
  一行，逻辑列整表达式一条。
- **多字段形态（实测修订⑥）**：源字段列英文分号 `;` 分隔，且每字段带
  `别名.字段`（多源时裸字段名有歧义）；单字段保持裸字段名。源表多表仍「、」。
- **包裹形态穿透缺口（缺口6）**：引擎穿透停在子查询别名（b.total_amt）→ 源表列
  保守标「（虚拟表 b）」+ 备注指路表3贴码，类型保守判数据加工（不编造物理源）。
- 终态口径：中间产物字段（如 record_cnt 进 tmp 未进终态）**不进本表**（Q2），
  交付门 info 级清单披露。
- 直取字段加工逻辑列留空；**字段逻辑拆解器**为 SPEC 适配层新构件：输入引擎跨步骤
  字段血缘链，输出结构化{表达式/常量/CASE}，纯渲染不碰引擎。

## 六、LTS 依赖 job ↔ 源表调度匹配（实测修订⑧，2026-11-02 第二轮）

**候选集 = 资产 F 任务（*_F）的 tskdep 依赖 job 指向的上游任务**——不是全量任务。
LTS 任务图（用户口述）：资产 job 的父 job 是 start/getdata 类根节点；依赖 job
（tskdep 型）的父 job = 资产 job，其 job 名 = 上游任务主 job 名（Pjob_X，X 即
上游表名）。**资产自身任务/主 job 一律不进候选**（曾因此把资产 job 填进源表行）。
上游任务索引底池 = 全量任务（`_all_raw_tasks` 私有键——上游通常不带本规则组
V_GROUP_CODE，不随 all_tasks 流动）。

匹配两层：

| 层 | 规则 | 备注标注 |
|---|---|---|
| 精确层 | tskdep job 名解出的表名 == 源表裸名（确定性） | 「按依赖job（tskdep）表名精确匹配」 |
| 模糊层·等值 | 归一化（去前缀/schema/分隔符）后相等 | 「调度信息按Pjob名精确匹配」 |
| 模糊层·包含 | 一侧含另一侧子串 | 「模糊匹配(包含)，请人工核对」 |
| 模糊层·相似度 | difflib ≥ `SIM_THRESHOLD`(0.6) 取最高 | 「模糊匹配(相似度0.xx)，请人工核对」 |

- **歧义保护**：最佳与次佳差 < `AMBIGUITY_MARGIN`(0.1) → 不自动填，列举待人工。
- 未解析到上游任务的 tskdep（制品内缺该任务）→ 不参与匹配，列举+标注
  「未找到对应上游任务」（不编造任务名）；tskdep 表名未命中源表 → 尾部列举。
- 无 F 任务 / F 任务无 tskdep → 调度列留空 + 两态披露（status: no_f_task/no_tskdep）。
- pjob 列 = tskdep job 名（平台约定即上游主 Pjob 名）。
- 常量阈值可调，真实制品持续校准（缺口 2）。

## 八、模板契约（列头指纹）
